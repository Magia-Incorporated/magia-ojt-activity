# Survival Nexus — Magia OJT

An outbreak has scattered the resistance. You are the developer rebuilding **Survival Nexus**, the application that coordinates fictional survivors, supplies, and infection reports. Start coding in Pack01 and expand the same project throughout the course.

## Your project repository

Use your personal public GitHub repository named **`Survival-Nexus`**, with **Survival Nexus** as its README title. If you have not created it yet, create it under your personal account as Public with a README; otherwise continue the existing project. Do not fork this company instruction repository as your application or delete unrelated existing work. Git/GitHub basics are assumed complete and are not repeated as activities.

Keep all records fictional. Do not add real names, trainee codes, contact details, real locations, credentials, or company/customer data. Public files and commit authorship identify a GitHub account; email privacy does not make it anonymous. Reuse your existing no-reply commit configuration and authentication workflow.

## Complete the work on your own

- **No AI or human hints.** Use the supplied instructions, official references, your own notes, normal editor features, and debugging tools.
- **Use Markdown for technical notes.** Your application itself uses HTML, CSS, JavaScript, JSON, and SQL as each mission requires. No Word documents are used.
- **Check actual behavior.** Record inputs, expected and actual outcomes, and corrections in the activity’s notes file. Keep required tests passing.
- **Apply the Git workflow you already know.** Review source changes, commit meaningful work, and push. When a mission uses a PR, self-review and merge it once its checks pass; no outside approval is required.
- **Continue by evidence.** A completed checklist is your checkpoint. There are no questionnaires, live demonstrations, oral examinations, or required feedback sessions.

Keep the public repository available for later review. No personal-information form or separate identity field is needed. Never copy private solution files into your project.
